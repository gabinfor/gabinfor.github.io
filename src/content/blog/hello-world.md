This is my first post. I'm going to use this site to write about the things I build and the things I'm learning.

## How this site works

Every post is a Markdown file in `src/content/blog/`. When I push to GitHub, an Action builds the site with [Astro](https://astro.build) and publishes it to GitHub Pages.

> Writing a post is as simple as adding a file and pushing.

Some things I want to try here:

- interactive graphics with WebGPU
- linking to other people's blogs (see the [blogroll](/blogroll/))
- maybe a live chat corner
